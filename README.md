Five Seconds to Explain the Glass — the one sentence a house cat would say in its own defence after knocking a glass off the table.

The glass was trespassing on a claimed sunbeam; the paw was diplomacy; gravity made the final decision.

## Run

```sh
python3 main.py
```

Writes the single sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: no network, no randomness, no model calls — the same sentence every run.
